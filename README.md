# School Lost & Found — MVP v0.1

A simple school Lost & Found web app built with React + Vite.

## Current features

- Lost / Found item reports
- Search
- Category filters
- Responsive item cards
- Add Item modal
- Browser localStorage persistence

## Run in VS Code

1. Open this folder in VS Code.
2. Open Terminal.
3. Run:

   npm install
   npm run dev

4. Open the local URL printed by Vite.

## Push to GitHub

Create a new EMPTY GitHub repository first, then run:

   git init
   git add .
   git commit -m "Initial Lost and Found MVP"
   git branch -M main
   git remote add origin YOUR_GITHUB_REPOSITORY_URL
   git push -u origin main
